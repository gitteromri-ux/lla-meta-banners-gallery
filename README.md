# LLA Meta &amp; Instagram Ad Banner Gallery

Production banner gallery for **Longevity Life Academy — The Longevity Masterclass** paid-media campaign featuring Julie Gibson Clark.

## 🔗 Live gallery

**https://gitteromri-ux.github.io/lla-meta-banners-gallery/**

## What's inside

Every banner delivered across the campaign, in **4 real Meta / Instagram ad sizes**, ready for upload to Ads Manager:

| Aspect | Dimensions | Where it runs |
|---|---|---|
| 1:1 Square | 1080 × 1080 | Instagram Post · FB Feed Square |
| 4:5 Vertical | 1080 × 1350 | IG / FB Feed Vertical (highest reach) |
| 9:16 Story | 1080 × 1920 | IG Stories · Reels · FB Stories |
| 1.91:1 Landscape | 1200 × 628 | FB Link Ad · Marketplace |
